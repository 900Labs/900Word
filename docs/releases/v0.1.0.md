# 900Word v0.1.0 Release Notes Draft

Status: unreleased draft.

`v0.1.0` is planned as the first public source release of 900Word. It is intended for developers and early testers who are comfortable building from source and reviewing the project boundaries before using the app with non-sensitive documents.

This release does not publish signed installers, notarized packages, automatic updates, package provenance, or binary artifacts.

## Public Release Scope

Public claims for `v0.1.0` are limited to:

- Local-first `.odt` document editing with ODT as the canonical saved format.
- Bounded DOCX import/export conversion for the supported subset documented in this repository.
- Current export and print paths: TXT, sanitized offline HTML, lightweight PDF snapshot export, and sanitized WebView/browser print preparation.
- No telemetry by default.

900Word does not claim broad Microsoft Word, LibreOffice, Google Docs, or ONLYOFFICE compatibility for `v0.1.0`. Any external office-suite behavior must be backed by generated or sanitized placeholder compatibility evidence before it is described as supported.

## Known Limitations

- No official signed installers, notarized packages, automatic updates, binary packages, or binary update channel.
- `.odt` is the canonical saved document format. DOCX is a conversion boundary and may degrade unsupported WordprocessingML structures with warnings.
- Print and PDF output use the current lightweight export paths. PDF pagination is limited to the existing lightweight exporter, and print pagination/layout depends on the browser or WebView print implementation.
- External office-suite behavior is not a compatibility promise unless release-candidate evidence records a `pass` or `degraded-documented` result for the claimed application and format.
- No cloud sync, accounts, collaboration, remote document storage, plugin runtime, macros, legacy binary `.doc`, or full-document encryption.
- Full Word/LibreOffice parity, deterministic pagination, richer style management, broad dictionary compatibility, and platform accessibility polish remain deferred.

## Deferred Binary Scope

Binary artifacts are out of scope for `v0.1.0`. A future binary release must separately define signing, notarization or platform-equivalent signing, package provenance, package privacy scanning, missing-artifact failure policy, runtime network evidence, and automatic update policy before installers or packages are published.

Do not attach local package outputs, screenshots, logs, private documents, or machine-specific paths to the `v0.1.0` source release.

## Privacy Posture

900Word is designed as a local-first editor with no telemetry by default. Public release materials must avoid local computer paths, hostnames, personal names, private documents, screenshots, generated package artifacts, account identifiers, cloud URLs, private endpoints, and real user data.

Compatibility testing must use generated or sanitized placeholder documents only. Generated evidence artifacts stay out of Git and must be referenced by generic artifact names or run IDs rather than local paths.
